# Chapter 1: Prologue & Sets — Collections, Functions & Isomorphisms

**Page Span:** `pp. 3–51`

**Theme:** Abstract theories as languages for defining tools; sets as unstructured collections of colored balls; functions as many-to-one maps; hom-sets, injections, surjections, bijections, isomorphisms, and currying.

## Global Invariants

- Lawvere Epigraph (p. 3): Visual abstraction as the bridge from internal elements to external relationships.
- Empty Set Initiality (p. 22): There is a unique function ! : ∅ → A to any set A.
- Singleton Terminality (p. 24): There is a unique function ! : A → 1 from any set A to a singleton set.
- Set Isomorphism (p. 48): f : A → B is an isomorphism iff g ∘ f = id_A and f ∘ g = id_B.

## Concept Stalks in this Chapter

- [Visual Abstraction & Lawvere's Perspective](../concepts/visual-abstraction-modes-of-knowledge.md) (`§1.1`, `pp. 3–12`): Dedication to F. William Lawvere and Bertrand Russell's definition of abstract theories as meta-languages for defining tools through visual diagrams rather than domain-bound formulas.

- [Injections, Surjections, Isomorphisms & Currying in Set](../concepts/functions-bijections-isomorphisms.md) (`§1.3`, `pp. 28–51`): Functions in mathematics vs. programming; function composition g ∘ f; injections (one-to-one), surjections (onto), and bijections; set isomorphisms via invertible arrow pairs; higher-order functions and currying.
