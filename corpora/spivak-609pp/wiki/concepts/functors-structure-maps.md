# Functors: Structure-Preserving Maps Between Worldviews (`F : C → D`)

> **Sheaf Stalk Location:** Chapter 5 (Basic Category Theory: Categories, Functors, Natural Transformations & Cat ≃ Sch) · Section `5.1.2–5.2` · **PDF Pages 285–337**

## 1. Epistemic Worldview & Intuition

A functor F : C -> D translates one categorical worldview into another while preserving identity morphisms and composition of paths. Consequently, functors automatically preserve all commuting diagrams and isomorphisms.

## 2. Formal Categorical Core

Definition 5.1.2.1 (p. 285): A functor F : C -> D assigns F(x) in Ob(D) to each x in Ob(C) and F(f) : F(x) -> F(y) to each f : x -> y in C, satisfying F(id_x) = id_{F(x)} and F(g o f) = F(g) o F(f). The category of small categories and functors is Cat.
