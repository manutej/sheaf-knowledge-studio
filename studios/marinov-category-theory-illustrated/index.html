⊘ Counterpoint · When Point-Free Externalism Loses Naive Intuition
In categories where the terminal object 1 is not a generator (for instance, in a monoid viewed as a one-object category BM or in a poset without a global unit), morphisms 1 → A no longer enumerate "internal elements." Marinov highlights this exact subtlety in Chapter 3 (): once we leave Set, we probe an object A using generalized elements X → A from arbitrary test objects X (the precursor to the Yoneda Lemma).

⊘ Counterpoint · Classical Excluded Middle vs. Constructive Computation (p. 184, p. 203)
While Classical Boolean Logic assumes P ∨ ¬P = ⊤ and ¬¬P → P, Marinov emphasizes in Chapter 5 () that programming types and general categories obey **Intuitionistic (BHK / Heyting) Logic**: you cannot construct an inhabitant of Either A (A → Void) for an arbitrary unknown type A without an explicit decision procedure.
